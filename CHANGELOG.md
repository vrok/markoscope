## 0.1.0 — 2026-10-14

First release.

- Reading themes: Reader, Clean, Sepia and Night
- Mermaid diagrams, syntax highlighting, tables and task lists
- Live reload when the file changes on disk
- Version history pane: changes highlighted in red and green, with a minimap of changes;
  quick successive saves count as one version
- Outline sidebar that follows the section being read
- Folders: browse their Markdown files in the sidebar and open them as tabs
- Close Tabs to the Left / Right
- Welcome window and File ▸ Open Recent with recent files and folders
- Open files and folders by dropping them on a window or the Dock icon
- Settings in `~/.markoscope/config.toml`, recent files in `~/.markoscope/history`
- Universal app (Apple silicon and Intel), macOS 13 or later
